How the Structures Connect

  
Suffix Array: all suffix positions of the ledger text sorted lexicographically. Pattern search becomes binary search over suffixes.

  
BWT: the character before each suffix-array position. Similar contexts cluster together, so repeated historical language compresses well.

  
FM Index: stores BWT plus occurrence counts and first-occurrence positions. Backward search finds a pattern without reconstructing the original descriptions.

  
Wavelet Tree: stores numeric scores recursively by value ranges. It answers rank and range-count queries over values such as “how many scores are 50 to 90”.
